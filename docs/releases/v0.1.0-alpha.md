# NEXMINT AI v0.1.0-alpha

## Summary

NEXMINT AI v0.1.0-alpha is an early testnet prototype for AI-powered NFT generation and launch infrastructure.

## Included

- Next.js creator interface
- Express API backend
- MongoDB models for collections, items, generations, mints
- BullMQ worker pipeline
- Single NFT generation flow
- Collection generation flow
- IPFS metadata pipeline
- ERC721A collection contract
- Collection factory contract
- Launchpad and creator dashboard prototype
- Base Sepolia/testnet-oriented setup

## Known Limitations

- Not audited
- Mainnet deployment not recommended yet
- AI provider quota/rate limits may pause generation
- IPFS/Filebase metadata pipeline still being hardened
- Custom single NFT contract minting is coming soon
- Deploy new single NFT contract mode is coming soon

## Next Milestones

- Production Filebase/IPFS pipeline
- Metadata/baseURI validation guard
- Default single NFT minter contract per chain
- Collection pre-deploy checklist
- Better retry/pause generation UX
- CI and contract test coverage
- Mainnet readiness checklist
